# 디자인 테스트용 사진 출처

이 폴더의 사진은 **시각 디자인 비교용 샘플**이다. WOLINK 프로젝트의 실제 결과물·증빙이 아니며, 포트폴리오 증거로 쓰지 않는다. 화면과 데이터(`data/samples.js` 의 `photo` 샘플)에도 “디자인 테스트 · 사진 출처 Unsplash” 로 표시한다.

## 사용 조건

- 라이선스: **Unsplash License** (https://unsplash.com/license) — 상업·비상업 무료 사용, 별도 허가·저작자 표시 불요(표시는 권장). 금지: 사진을 바꾸지 않고 판매하거나 유사 서비스에 모아 제공하는 것.
- `plus.unsplash.com/premium_photo-…` 로 제공되는 Unsplash+ 사진은 조건이 다르므로 **제외**했다. 아래 5장은 모두 `images.unsplash.com` 의 일반 사진이다.
- 받은 크기: 긴 변 1800px (`?w=1800&q=82&fm=jpg&fit=max`). 원본은 더 크다.

## 선정 기준

한 ‘프로젝트’처럼 읽히도록 **서울 골목·동네 길** 주제로 통일했고(WOLINK 의 동네 맥락), 따뜻한 저녁빛·벽돌·전선이 있는 사진으로 색감을 맞췄다. 세로 2장 + 가로 3장으로 구도를 섞었다.
